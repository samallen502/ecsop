# Military Transcript Procurement

*   [ ] For a USAF soldier or veteran, execute the following process:

    * [ ] Go [here](https://afvec.us.af.mil/afvec/Home.aspx)
    * [ ] Select the "advanced" button

    <figure><img src="../../.gitbook/assets/advanced (1).png" alt=""><figcaption></figcaption></figure>

    * [ ] Select the "proceed" button

    <figure><img src="../../.gitbook/assets/proceed (1).png" alt=""><figcaption></figcaption></figure>

    * [ ] Login (or register, if appropriate)
      * [ ] If issues are encountered, alternative request methods are available [here ](https://www.airuniversity.af.edu/Barnes/CCAF/Display/article/803247/community-college-of-the-air-force-transcripts/)
    * [ ] Have the CCAF transcript electronically delivered to Sullivan University
